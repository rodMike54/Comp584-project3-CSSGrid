# COMP 584 Project 3 - CSS Grid

This is my Project 3 for COMP 584. I converted my previous Flexbox assignment to CSS Grid and kept the technology topic.

The layout uses grid columns, grid rows, gaps, and grid line placement. Media queries change the layout for mobile, tablet, and desktop screens.

- `grid-auto-rows`: Sets automatically created rows to a minimum height of 150px while allowing them to grow with the content.
- `justify-items`: Makes the articles stretch across the width of their grid cells.

Comments in style.css explain how these properties work.
